### Вспомогательные модули
* base_scripts.py - скрипт регистрация курьера и получения ответа и данных для создания курьера и логина  
* data.py - данные для запросов (payload)  
* response_text.py - данные для проверок текстов ответа  
* urls.py - URL методов
